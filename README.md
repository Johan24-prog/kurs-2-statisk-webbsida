# .NET25: Statisk webbsida

En valfri statisk webbsida med HTML och CSS.

## Hur allt fungerar

Innan utveckling påbörjas ska **node** och **npm** installeras, och följande
kommand ska köras:

```bash
npm install
```

För att köra testerna ska följande kommand köras:

```bash
npm test
```

Uppladdning via commits och push fungerar som det brukar!

## Betyg

Ett tips är att läsa kursplanen för detaljer, men för den här uppgiften gäller
följande:

### G

Alla **G** tester ska vara gröna, och ska uppfyllas så att alla delar faktiskt
används på sidan. Ett tomt element bara så att det finns räknas inte, och gömmer
man en av de obligatoriska färgerna bakom ett annat element räknas inte det
heller som att färgen används!

### VG

Utöver kraven för godkänt ska alla **VG** tester också vara gröna.

Sidan ska även fungera på både mobila enheter liksom vanliga datorer, dvs alla
olika skärmstorlekar ska fungera inom en rimlig marginal utan att webbsidan går
sönder.

Sidan ska även implementera grundläggande tillgänglighetsanpassning, exempelvis
alt-texter, tydliga färgkontraster och semantisk HTML (_inte divs överallt,
använd header, main, footer, h1, h2 osv, rätt element för rätt sak, med enstaka
divs på de områden som är kvar!_).
