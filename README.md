# Min statiska webbplats

Jag har byggt en enkel, personlig webbplats med HTML och CSS. Den innehåller en välkomstsida med navigering till tre delar:

- **Om mig** – en kort presentation.
- **Bilder** – två bilder med olika utseende: en svartvit och en suddig.
- **Kontakt** – kontaktuppgifter.

Webbplatsen använder semantiska HTML-element som `header`, `nav`, `main`, `section` och `footer`. CSS:en ger sidan en grönblå färgpalett, centrerat innehåll och bildramar. Layouten anpassas för mindre skärmar genom en media query som ändrar navigeringen och innehållets marginaler.
